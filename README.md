# The Lantern Orchard

The Lantern Orchard is an original, offline browser game: guide a small lantern through a moonlit orchard, aim light at incoming thorn creatures, and use pulses and wave upgrades to survive four nights. The game runs locally in your browser and does not need a network connection.

## Play

| Input | Action |
| --- | --- |
| WASD | Move |
| Mouse | Aim; hold the left button to fire |
| Space or Shift | Pulse |
| P or Escape | Pause or resume |
| M | Mute or unmute |
| Enter or click | Start or restart |

## Run locally

With Node.js 22 or newer, run the included static server from the repository root:

```sh
node serve.ts
```

Then open [http://localhost:8080](http://localhost:8080). The game is served from `game/`.
